# 🌦️ Weather App

A modern and responsive Weather Application built using HTML, CSS, and JavaScript. This project allows users to check real-time weather conditions for any city around the world using weather data APIs.

---

## 🌐 Overview

The Weather App provides accurate and up-to-date weather information through a clean and intuitive user interface. Users can search for any city and instantly view details such as temperature, humidity, wind speed, and current weather conditions.

The project demonstrates API integration, asynchronous JavaScript, and responsive web design.

---

## 🎯 Objectives

* Provide real-time weather information
* Practice API integration with JavaScript
* Build a responsive and user-friendly interface
* Improve frontend development skills
* Demonstrate practical use of asynchronous programming

---

## ✨ Features

### 🔍 City Search

Search weather information for any city worldwide.

### 🌡️ Real-Time Temperature

Displays current temperature in Celsius.

### 💧 Humidity Information

Shows live humidity levels.

### 💨 Wind Speed

Provides current wind speed data.

### 🌤️ Dynamic Weather Icons

Automatically changes icons based on weather conditions.

### ❌ Error Handling

Displays appropriate messages for invalid city names.

### 📱 Responsive Design

Works smoothly on desktop, tablet, and mobile devices.

## 🚀 How It Works

1. User enters a city name.
2. The application sends a request to the weather API.
3. Weather data is fetched in real time.
4. Temperature, humidity, wind speed, and weather conditions are displayed.
5. The weather icon updates according to the current condition.

---

## 🔗 API Used

This project uses the OpenWeather API to retrieve real-time weather information.
